# Style guide

- **Look:** flat 2D vector, bright colors, round shapes, gentle bouncing.
- **Tone:** warm, simple, encouraging. Never scary, violent or mocking.
- **Language:** short sentences, common words, one new word at a time.
- **Voice:** Kokoro, pitched up slightly. Never clone a real child's voice.
- **Safety:** every lesson passes `src/safety.py`; watch each video before making it public.
