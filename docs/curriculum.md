# Curriculum plan

Folder = topic. Age bands: A (3-5), B (6-8), C (9-12).

| Folder | Topics | Ages |
|---|---|---|
| numbers | counting 1-10, 1-100, skip counting | A, B |
| math | adding, subtracting, multiplying, dividing | B, C |
| animals | names, sounds, baby animals, homes | A, B |
| language | reading, letters, plurals, English words | A, B, C |
| life-skills | planning, problem solving, people skills, leadership, research, reporting | B, C |

Each video teaches ONE idea, repeats it, and ends with a recap.
